# QuantumLab — Interactive Physics Simulator

Open `index.html` in a browser.

Features:
- PN-junction I–V simulator with temperature, saturation current and ideality factor controls
- Constants/reference section
- Quantum particle-in-a-box wavefunction simulator
- Simple harmonic motion simulator
- 1D heat diffusion numerical simulation
- User-created mathematical graph editor
- Short concept notes and formulas
- Responsive UI, animated reveal effects and tabbed simulations

The page uses Chart.js from a CDN, so an internet connection is needed for charts unless Chart.js is downloaded locally.
